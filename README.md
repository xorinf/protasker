# ProTasker

A full-stack MERN project management platform built from scratch as a senior-level engineering exercise.

## Goals
- Learn MERN stack deeply
- Follow professional engineering practices
- Build a production-grade application

## Tech Stack (current)
- Node.js (LTS)
- JavaScript ES2023 (ES Modules)
- Vite 5.4+ (Build System & Dev Server)
- HTML5 & CSS3 (Modern Design System)
- Git & GitHub (Feature branches, PRs)
- ESLint + Prettier

## Getting Started

### Installation
```bash
npm install
```

### Development
Start the development server with Hot Module Replacement (HMR):
```bash
npm run dev
```
Visit http://localhost:5173

### Production Build
Create optimized production bundle:
```bash
npm run build
```

Preview production build locally:
```bash
npm run preview
```

### Code Quality
Lint your code:
```bash
npm run lint
```
